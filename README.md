# Student Placement Prediction App

A machine learning classification project that predicts whether
a student is likely to be placed based on academic and skill-related
features.

This is a test project just to test my abilities....

## Features
- CGPA
- Internships
- Projects
- Skills
- Communication

## Model
Decision Tree Classifier

## Technologies
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
